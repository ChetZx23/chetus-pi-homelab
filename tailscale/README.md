# Tailscale

Tailscale provided private remote access to the homelab.

It allowed the Raspberry Pi and trusted devices to communicate over a private network without requiring the homelab services to be directly exposed to the public internet.

## Role in the Homelab

Tailscale was used primarily for remote administration and accessing self-hosted services while away from the local network.

This avoided the need for conventional router port forwarding and reduced the public exposure of the server.

## Key Features Used

- Private remote access
- Secure device-to-device connectivity
- Remote SSH access
- Access to self-hosted services
- No public port forwarding

## Security

No Tailscale authentication keys, credentials, or private network addresses are stored in this repository.
