# Server Security

Security measures implemented on the Raspberry Pi homelab.

## UFW

UFW (Uncomplicated Firewall) was enabled on the Raspberry Pi to manage incoming network connections.

## Fail2Ban

Fail2Ban was enabled on the system to provide protection against repeated failed authentication attempts.

## SSH

SSH was used for remote administration of the Raspberry Pi.

## Tailscale

Tailscale was configured for remote access to the Raspberry Pi.

This allowed the server to be accessed remotely without using router port forwarding.

## Network Exposure

No router port forwarding was configured for the homelab.

## Credentials

Passwords, private keys, authentication keys, and other sensitive information are not included in this repository.

The repository is intended to document the homelab configuration and the work carried out during the project without exposing private information.
