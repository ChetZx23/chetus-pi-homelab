# Portainer

Portainer is used as the graphical management interface for the Docker environment.

It provides a web interface for:

- Managing containers
- Deploying Docker stacks
- Viewing container logs
- Starting and stopping containers
- Restarting services
- Managing Docker images
- Inspecting the Docker environment

Portainer was used extensively during the setup and maintenance of the homelab, while SSH was retained for system-level administration and troubleshooting.
