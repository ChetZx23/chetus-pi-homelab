# Heimdall

Heimdall was used as the central dashboard for the homelab.

It provided a simple starting point for accessing the various self-hosted services running on the Raspberry Pi.

## Role in the Homelab

Rather than having to remember individual service addresses, Heimdall provided a single interface from which the services could be accessed.

It was deployed as a Docker container and managed alongside the rest of the homelab infrastructure.

## Key Features Used

- Centralized service dashboard
- Quick access to self-hosted applications
- Docker-based deployment
- Simple organization of homelab services
